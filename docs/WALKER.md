# Walker: launcher and system menu

Launcher ([walker](https://github.com/abenz1267/walker) + elephant) and a system menu in the style of
[Omarchy](https://github.com/basecamp/omarchy) 3.8.4, with the monochrome look of the rest of the
desktop. It was built in seven phases (24–25 September 2026); the original plan is summarized at
the end in «History and decisions».

Files: `home/.config/walker/`, `home/.config/elephant/`, `home/.config/systemd/user/`
(`walker.service`, `elephant.service`), the scripts in `home/.local/bin/` and the pacman hook
`system/etc/pacman.d/hooks/walker-restart.hook`. Keybinds: [HYPRLAND.md](HYPRLAND.md#keybinds).

## Configuration, menu and scripts

- **Packages:** `walker` and `elephant-bin`, plus the `elephant-*-bin` providers: desktopapplications, calc, clipboard, files, runner, symbols, unicode, websearch, providerlist, menus, windows, bookmarks, todo, archlinuxpkgs, bluetooth, playerctl, wireplumber and snippets.
- **First failure:** walker showed "No Results" because only the `elephant-bin` core was installed, without providers.
- **User services** (start with the session):
  - `~/.config/systemd/user/elephant.service` (recovered from the Omarchy backup).
  - `~/.config/systemd/user/walker.service`, with `walker --gapplication-service` so it opens instantly.
- **Autostart without uwsm:** when logging in with the plain "Hyprland" session instead of "Hyprland (uwsm-managed)", `graphical-session.target` is not reached and the services do not start. So `conf/autostart.lua` also starts them with `systemctl --user start` (a no-op if they are running). greetd starts the uwsm session.
- **Config (mirrors Omarchy 3.8.4):** `~/.config/walker/config.toml` only holds what differs from `/etc/xdg/walker/config.toml` (walker merges them): fixed focus, wrap-around selection, no hint bar at the bottom (tried and removed), no F1–F4, emoji as a list, 256 results and the «Reiniciar walker» (restart walker) emergency entry. The prefixes are walker's (`;` providers, `>` runner, `/` files, `.` symbols, `!` todo, `%` bookmarks, `=` calculator, `@` web, `:` clipboard, `$` windows).
- **elephant:** `~/.config/elephant/` with `calc.toml` (no async), `desktopapplications.toml` (name only, no actions or history) and `symbols.toml`, which pastes the emoji into the active window with `hyprctl dispatch 'hl.dsp.send_shortcut({ mods = "SHIFT", key = "Insert", window = "activewindow" })'` (in Hyprland 0.56 the classic `sendshortcut` syntax does not work). Careful: trying that dispatcher by hand really pastes the clipboard.
- **`nothing` theme** (`~/.config/walker/themes/nothing/`): Omarchy's `layout.xml` (644 px, one column, 300 px tall). **Since 28 Sep it follows the design of the shell's Settings window** (before: radius 18, hint text in Doto capitals and the selected entry inverted in white, which did not match Settings, where active things are red): black panel with a 1 px border and radius 14 (Settings' card radius), search field like Settings' fields (`control`, border, red when focused), 14 px text, entries in `fgSoft` with a `surface` hover, and the selected one like the current page in the sidebar (`selSoft` background, 3 px red mark on the left via `box-shadow: inset`, white bold text), a thin scrollbar (you can tell when there are more entries) and errors with a `selSoft` background and a red border. Icons in color (`-gtk-icon-filter: grayscale(1)` works in GTK4 and was tried, but color was preferred). Colors: `colors.css` holds Nothing's and `tema.css` the active theme's, **with every token of `Theme.qml`** in snake_case (`bg_alt`, `control`, `control_hi`, `fg_soft`, `sel`, `sel_hi`, `sel_soft`, `sel_text`…), generated by `quickshell/scripts/tema.sh`. There are no `item_*.xml`: walker uses its own. `conf/rules.lua` disables the animation of the `walker` layer.
- **Row height and main menu height** (28 Sep): rows are **exactly 44 px** (`min-height` on `.item-box`, no padding on the text) and the subtitle is hidden with `opacity: 0` and 1 px (before it used `font-size: 0`, which Pango may treat as the default size, making rows taller). `menu` sizes the main menu as sections × 44 + 6 px of slack: it used to be exactly × 44, and at the laptop's 1.8 scale rows could end up taller than 44 px and clip the last section without anyone noticing (the scrollbar was invisible).
- **Scripts** (`~/.local/bin/`, linked one by one): `walker-launch` starts the services if needed and opens walker at 644×300 (used by `SUPER+ALT+SPACE` and `SUPER+V`); `walker-restart` restarts elephant and walker, also as root from the pacman hook (through `systemd-run --uid`).
- **PATH:** `~/.local/bin` was not in the PATH of Hyprland or the services. `conf/env.lua` adds it (without repeating it on reload) and `conf/autostart.lua` passes `PATH` to the services with `import-environment`; walker needs it for the emergency entry and the menus.
- **Services:** `Restart=always`, `RestartSec=2`; walker runs with `GSK_RENDERER=ngl` (GTK's OpenGL renderer). It used to use `cairo` (software, like Omarchy, to avoid NVIDIA issues), but that left remains of the previous frame when results changed: stray white dots, which were the dots of the «i»s of the entry that used to be on that row (27 Sep). With `ngl` it does not happen, on the NVIDIA monitor too.
- **Pacman hook** `/etc/pacman.d/hooks/walker-restart.hook` (template in `system/`): after upgrading `walker` or `elephant*` it runs `~/.local/bin/walker-restart` (install.sh fills in your home path).
- **System menu** (`~/.local/bin/menu`, ≈ `omarchy-menu`). **Main menu (`SUPER+SPACE`) with a search field**: it is regular walker with the `menu` provider set (`[providers.sets.menu]` in `config.toml`): without typing it shows the sections (elephant Lua menu `menus/sistema.lua`, `FixedOrder`); typing searches **every** entry of the menu and its submenus with its path («Actions › Screenshot › Region», `menus/sistemabuscar.lua`) and the apps. The entries come from **one table** in the script (`ENTRADAS`: path|icon|text|target; `menu --entradas` prints it and both `.lua` files read it); `menu hacer <id>` runs an entry and `menu --desde-principal <path>` opens a submenu from the main menu (Escape goes back to it). To add an entry: one line in `ENTRADAS` and its case in `hacer`, plus its Spanish in `~/.config/quickshell/i18n/es.js`. **Language:** the table's paths and texts are in English and are also the identifiers of hidden entries, section order and custom entries' paths in `settings.json` (`menuHidden`, `menuOrder`, `menuCustom`); they are shown in the interface language (`t`, `i18n/i18n.sh`; `menu --entradas` prints them translated for the elephant menus, `--entradas-todas` in English for Settings → Menu). Settings from before this change (Spanish names) are renamed once by `Config.migrateMenu()`, and `menu captura`, `menu sistema`… still work as aliases.
  - **Careful:** if walker gets a `-s <set>` that is not in its config (e.g. because it was not restarted after adding it), **it crashes** («can't find specified set») and systemd stops restarting it; another walker also keeps the D-Bus name (`Unable to acquire bus name 'dev.benz.walker'`). Fix: kill the `walker` processes that are not `--gapplication-service` and `systemctl --user reset-failed walker && systemctl --user start walker`.
  - **Customizable from Settings → QuickShell → Menu** (27 Sep): hidden entries, section order and custom entries, in `settings.json`; the script filters the `ENTRADAS` table with `jq` when it opens.
  - Submenus: walker in `--dmenu` mode (295 px or wider). Apps, Learn (wikis), Actions (Screenshot, Record, Do Not Disturb, idle lock, laptop screen), Style (Wallpaper, Appearance), Settings, Install (Package, AUR, Flatpak, WebApp, TUI), Remove (Package, Flatpak, WebApp, TUI), About (`fastfetch` in the floating terminal), Update ( `~/.config/quickshell/scripts/actualizar.sh` → `sudo arch-update --menu`, which waits for a «Close» button instead of «press a key»; repos only; firmware with `fwupdmgr`; restart walker or the shell) and System. Package tools run in a floating terminal of class `menu-terminal`. `menu <submenu>` opens one directly (Escape closes). **`SUPER+SPACE` with a menu open closes it completely**, from a submenu too: the bind has `submap_universal = true` (otherwise it does not exist inside the `menu` submap) and the second `menu` leaves `$XDG_RUNTIME_DIR/menu-cerrar` before `walker --close`; the first one sees it and ends with `kill $$` (`menu()` runs inside `$(…)`, where `exit` would only leave the subshell and go back to the previous menu). The width of the menus, `menu-input` and `menu-select` comes from the longest text (`wc -L` × 10 px + 100, minimum 295). Submenus have no search field and **Backspace goes back** like Escape: while one is open, `menu` switches Hyprland to the `menu` submap (`hl.define_submap` in `conf/keybinds.lua`), where Backspace runs `menu-atras`; when it closes it goes back to `reset` (and `menu-atras` clears it if it were left on without a menu). `BackSpace` cannot go in walker's `close`: it closes even with text typed. Careful when testing: `wtype -k BackSpace` does not trigger Hyprland binds.
  - **`captura pantalla|zona|ventana|texto`** (screen, region, window, text): freezes the screen with `hyprpicker -r -z`, selects with `slurp`, saves to `~/Pictures/Capturas`, copies to the clipboard, and the notification opens `satty` to annotate; `texto` runs the region through `tesseract -l spa+eng`.
  - **`grabar [--audio] [--micro]` / `grabar --parar`** (record / stop): `gpu-screen-recorder` of the chosen monitor or region, to `~/Videos/Grabaciones`; when it stops, a notification with a thumbnail.
  - **`paquetes repos|aur|flatpak|quitar|quitar-flatpak`** (≈ `omarchy-pkg-install`, `-aur-install` and `-remove`): an `fzf` list with the description below (`pacman -Sii`, `yay -Siia`, `flatpak remote-info`; in the AUR, `alt-b` shows the PKGBUILD), Tab to mark several, monochrome colors and red when removing. It asks for sudo once and keeps it. Flatpak installs system-wide from Flathub with `sudo` (there is no polkit agent) and removal also deletes unused runtimes. Removing packages only lists explicitly installed ones (`yay -Qqe`). If cancelled (exit 130), the terminal closes without waiting for a key. Needs `fzf`.
  - **`webapp crear|quitar|abrir <url>`** (create / remove / open; ≈ `omarchy-webapp-install`/`-remove`/`omarchy-launch-webapp`): asks for a name and URL with walker, downloads the favicon (Google's favicon service; if it fails it asks for a PNG URL or uses a generic icon) and creates `~/.local/share/applications/<name>.desktop` with `Exec=~/.local/bin/webapp abrir <url>` (absolute path, in case elephant does not have `~/.local/bin` in its PATH). It opens with `--app=` of the default browser if it is Chromium-based, otherwise with **chromium** (Firefox has no app mode); without chromium it warns. The `.desktop` files carry `X-Creado-Por=webapp` so they can be listed for removal.
  - **`tui crear|quitar`** (≈ `omarchy-tui-install`/`-remove`): name, command, floating or tiled window and an optional icon; the `.desktop` opens `alacritty --class TUI.float|TUI.tile -e <command>`. `conf/rules.lua` makes `TUI.float` floating, centered and 875×600 (like Omarchy). Marked with `X-Creado-Por=tui`.
  - **Wallpaper:** elephant Lua menu `~/.config/elephant/menus/fondos.lua` (`walker-launch -m menus:fondos`) with the images in `~/Pictures/Wallpapers` and a preview; applies with `qs ipc call wallpaper set <path>` or `dots`.
  - **Shell IPC used by the menu** (in `shell.qml`, see [QUICKSHELL.md](QUICKSHELL.md)): `notifications dnd` (toggles Do Not Disturb and returns the state) and `wallpaper set|dots`.
  - **Laptop screen:** `hyprctl dispatch 'hl.dsp.dpms({ action = "toggle", monitor = "eDP-1" })'` (only turns that screen off; verified).
  - Packages: `fzf hyprpicker satty tesseract tesseract-data-spa tesseract-data-eng gpu-screen-recorder fwupd`.
- **Helpers:** `menu-atajos` (keybind list from `hyprctl binds -j`; `--print` prints it to the terminal), `menu-input` (ask for a text) and `menu-select` (pick an option), all with walker `--dmenu`.
- **Keybinds:** see the table in [HYPRLAND.md](HYPRLAND.md#keybinds) (launcher, menu, keybinds, clipboard, emoji, screenshots and recording).

## History and decisions

**Reference:** Omarchy v3.8.4 (the last 3.x). There is no local copy: to check it,
`git clone --depth 1 --branch v3.8.4 https://github.com/basecamp/omarchy` into a temporary folder
and read `config/walker/`, `config/elephant/`, `default/walker/themes/omarchy-default/`,
`bin/omarchy-menu*`, `bin/omarchy-capture-*`, `bin/omarchy-pkg-*`, `bin/omarchy-webapp-*` and
`bin/omarchy-tui-*`. Do not recall from memory what is not there.

| Topic | Decision |
|---|---|
| Scope | Launcher + system menu + helpers + keybinds |
| Look | Same design as the Settings window (since 28 Sep; see the theme above), icons in color, no hint bar |
| Prefixes | walker's, not Omarchy's |
| Main menu | `SUPER+SPACE`, searching apps and every entry; `SUPER+ALT+SPACE` opens only the apps |
| Submenus | No search field; Backspace and Escape go back; `SUPER+SPACE` closes |
| The menu's «Ajustes» | Opens the shell's Settings window |
| Log out | `hyprctl dispatch 'hl.dsp.exit()'`, without `hyprshutdown` |
| Packages | fzf in a floating terminal, like Omarchy, plus Flatpak |
| `arch-update` | Rewritten in the style of Omarchy 4.0 (see [SYSTEM.md](SYSTEM.md#snapshots-snapper--limine)); if the snapshot fails, it aborts |

Phases: 0 `arch-update`; 1 walker and elephant config; 2 `nothing` theme; 3 startup, services,
`PATH` and pacman hook; 4 system menu, screenshots, recording and wallpapers; 5 helpers
(`menu-atajos`, `menu-input`, `menu-select`); 6 keybinds; 7 verification (all tested by hand, and
the hook with `yay -S walker`). Added later: search in the main menu, Backspace in submenus, fzf
installer and Flatpak, web apps and TUIs, «About» and `SUPER+Escape` → «System» submenu.

**Lessons (not to repeat):**

- `hl.dsp.send_shortcut(…)` **really pastes** the clipboard into the active window: do not try it by hand.
- `wtype -k <key>` reaches walker but **does not trigger Hyprland binds**: to test a bind, run its command.
- walker windows **grab the keyboard**: if one is opened for testing while the user types, the text ends up in walker. Warn first.
- Opening walker right after closing another one (≈0.5 s) sometimes does not show it: `menu --desde-principal` waits 0.3 s.
- A `-s <set>` walker does not know yet brings it down (see above how to recover).
- `pkill -f <text>` also kills the very command that contains that text: close windows by their PID (`hyprctl clients -j`).
- walker is from the AUR: reinstall it with `yay -S walker`, not `pacman -S`.
